# Session D-Bus is the plasmoid–helper IPC

`org.kde.plasma.workspace.dbus` ships with Plasma 6 and talks to the session bus without Plasma5Support or a custom C++ plugin. One helper can serve several widget instances; a missing service maps to Unknown Allowance; log-watch can push instead of polling. Localhost HTTP is easier to curl but puts a loopback listener next to `/login`. v1 IPC is D-Bus. Keep the helper’s JSON shape transport-agnostic.
