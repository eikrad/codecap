# List Price is USD; Display Currency is FX only

Consumed Usage money is estimated at Anthropic’s published USD token rates (the same worldwide, aside from inference-geo multipliers). Regional Pro/Max sticker prices and VAT are checkout, not a second token tariff. We store/calculate List Price in USD and convert for display with a per-widget Display Currency (default: desktop locale). We do not invent per-country token price books.
